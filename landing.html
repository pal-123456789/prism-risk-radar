Code review is the last line of defense. But reviewers are human, attention is finite, and the tools that help all want to upload your source to a cloud. PRism gives you the same help — without ever seeing your code.

How it works

A real static-analysis pipeline, running in a browser tab.

Paste a git diff. Everything below happens locally, deterministically — the same diff always yields the same report.

01 · PARSE

Read the change

A unified-diff parser turns the paste into files, hunks, and added lines — including combined merge diffs.

02 · TOKENIZE

Mask strings & comments

A per-language tokenizer hides text so rules match real code, not a mention of eval in a comment.

03 · DETECT

47 CWE-tagged rules

Pattern rules plus a Shannon-entropy secret detector flag danger, each with a reason, a fix, and a confidence.

04 · SCORE

An explainable waterfall

Signals become an auditable score you can watch add up — never a black box — with a per-file risk breakdown.
